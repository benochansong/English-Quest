# English Quest 0.2 — 잃어버린 말의 왕국

**시작하려면 `EnglishQuest.html` 파일을 더블클릭하세요.** Windows에서 Chrome 또는 Microsoft Edge로 열고 **게임 시작**을 누르면 됩니다. 게임에는 설치, 회원가입, 인터넷 연결이 필요하지 않습니다. 그림과 효과음도 이 파일 안에 들어 있습니다.

GitHub에서 받는 경우 0.2 개발 브랜치 `feature/english-quest-v0.2`에서 **Code → Download ZIP**을 선택한 뒤 먼저 압축을 풀어 주세요. 또는 `EnglishQuest.html` 파일 페이지에서 **Download raw file**로 게임만 저장할 수 있습니다. GitHub의 파일 보기 화면에서는 게임이 실행되지 않습니다.

**0.1에서 이어서 하기** — 예전 게임을 닫고 새 HTML을 기존 `EnglishQuest.html`과 같은 폴더, 같은 이름으로 교체하세요. 이전에 사용한 브라우저와 프로필로 열어 **이어하기**를 누릅니다. 기존 체력·레벨·경험치·금화·완료한 길·학습 기록·설정을 새 저장 공간에 복사하고 예전 저장본도 보존합니다. 처음부터 다시 하려는 경우에만 **게임 시작**을 누르세요.

## 첫 모험

1. 로완의 이야기를 읽고 **숲 지도 펼치기**를 누릅니다. 이야기는 건너뛸 수 있습니다.
2. **이슬 맺힌 숲길**을 열고 로완의 수첩에서 영어 표현을 보고 **뜻·해설 보기**를 눌러 뜻, 예문 번역과 쓰임을 확인합니다. 다시 연습하고 싶은 카드는 **복습 표시**를 누릅니다. 영어 음성이 설치된 브라우저에서는 **발음**을 누를 수 있습니다.
3. **전투 시작 → 검격**을 누르고 보기 하나를 고릅니다. 결과와 해설을 읽은 뒤 **계속 · 행동 실행**을 눌러야 다음 행동으로 넘어갑니다.
4. 숲 슬라임과 수정 슬라임을 차례로 이기면 **고요한 왕의 정원**이 열립니다. 왕을 물리치고 로완에게 돌아가면 챕터가 끝납니다.

| 기술 | 도전 | 정답 효과 |
| --- | --- | --- |
| 검격 | 단어 뜻, 이후 숲길에서는 번역이나 듣기 | 적에게 검 피해 |
| 화염 마법 | 영어 문장의 빈칸 | 마법 피해, 성공 후 두 턴 대기 |
| 수호 방패 | 짧은 표현의 뜻 | 이번 반격 피해 60% 감소 |
| 치유 마법 | 단어를 순서대로 눌러 문장 만들기 | 체력 최대 20 회복, 성공 후 세 턴 대기 |

처음에는 검격을 익힙니다. 두 번째 숲길부터 네 기술을 모두 쓸 수 있습니다. 단어 배열을 바꾸려면 **한 단어 되돌리기**를 누르세요. 왕이 힘을 모을 때에는 반격이 없고, 그 다음 턴 공격은 두 배 피해를 줍니다. 듣기 음성이 없거나 잘 들리지 않으면 화면의 영어 문장을 읽거나 **문장 보기**를 누르세요.

전투에 들어갈 때 체력을 모두 채웁니다. 두 번, 세 번, 네 번 연속 정답을 맞히면 각각 공격 피해가 5%, 10%, 15% 늘어납니다. 오답을 내면 연속 기록은 0으로 돌아갑니다. 보너스는 검격과 화염의 피해에 적용되며 화면에는 적의 남은 체력에서 실제로 줄어든 양이 표시됩니다.

왕은 마력을 모은 다음 턴에 **왕관 강타**를 사용합니다. 노출된 수정핵을 공격하면 두 배 피해를 줄 수 있습니다. 수호 방패에 성공하면 이번 피해가 줄고 **다음에 적중하는 검격이나 화염에 피해 12**가 추가됩니다. 왕의 체력이 절반 이하가 되면 다음 반격을 마친 뒤 2단계에 들어가 강타가 더 강해집니다.

첫 승리에는 경험치와 금화를 받습니다. 이미 완료한 숲길은 횟수 제한 없이 다시 플레이할 수 있습니다. 연습 전투의 답변은 학습 기록에 반영되고, 경험치와 금화는 각 스테이지의 첫 승리 때만 지급됩니다. 0.1을 오래 플레이해 레벨 4 이상이 된 경우, 이미 완료한 숲길에서는 적의 체력과 공격도 모험가의 능력에 맞춰 조정됩니다. 쓰러지면 **다시 도전**할 수 있습니다.

## 지도, 복습과 학습 기록

- **숲 지도** — 지도 위 표식을 누르면 잠긴 장소도 미리 살펴볼 수 있습니다. 오른쪽 탐험 경로에서 열린 숲길을 고르면 수첩으로 들어갑니다. 작은 화면에서는 경로가 지도 아래에 있습니다.
- **단어 도감** — 표현별 뜻, 예문, 누적 정답·오답 횟수가 표시됩니다. 수첩에서 만나면 ‘익히는 중’, 틀린 뒤 두 번 연속 정답을 내기 전까지는 ‘복습 필요’, 세 번 연속 맞히면 ‘익숙한 표현’으로 표시합니다.
- **복습** — 틀린 문제나 수첩에 표시한 표현의 **풀어보기**를 누릅니다. 전투처럼 답을 선택하거나 단어를 배열한 뒤 해설을 읽습니다. 복습에서 틀리면 바로 다시 풀 수 있습니다. 연속으로 맞히면 다음 복습이 1일, 3일, 7일 뒤로 옮겨갑니다. 예정일 전에도 연습할 수 있습니다.
- **학습 기록** — 만난 표현, 누적 정답률, 복습할 표현, 익숙한 표현, 챕터 진행과 업적 다섯 가지를 확인합니다. ‘최근 정답률 변화’는 최근 5회와 직전 5회의 차이를 보여 줍니다. 0.1에는 답변 순서가 없어서 이 비교는 업그레이드 후 응답 10회부터 시작합니다. 수치는 게임 안에서의 연습 기록입니다.
- **출제** — 배운 표현 중 최근 두 문제는 가능한 한 피하고, 복습 기한이 지난 오답이나 표시한 표현을 우선합니다. 같은 문제를 계속 보여 주지 않도록 전투 안에서 나온 횟수도 고려합니다.

## 저장과 설정

학습 기록과 전투 보상은 같은 브라우저에 자동 저장됩니다. 다시 열어 **이어하기**를 누르면 지도로 돌아옵니다. 전투 도중 닫으면 해당 전투를 처음부터 시작하고, 이미 답한 학습 기록은 남습니다. 파일을 같은 위치에 두고 같은 브라우저로 여세요. 시크릿 창, 브라우저 데이터 삭제, 파일 이동은 저장 기록에 영향을 줄 수 있습니다.

화면 위 메뉴나 **Esc**로 일시 정지하고 효과음, 음량, 발음을 바꿀 수 있습니다. 저장을 지우려면 **설정 → 진행 초기화 → 초기화하고 계속**을 누릅니다. 메뉴는 키보드의 Tab으로 이동하고 Enter 또는 Space로 선택할 수 있습니다.

## 게임을 수정하려면

플레이에는 HTML 하나면 충분합니다. 내용을 고치려는 경우에는 소스 전체와 Node.js가 필요합니다. 먼저 폴더를 복사해 보관하세요. 수정 후 프로젝트 폴더에서 `node build.mjs`를 실행하면 새 `EnglishQuest.html`이 만들어집니다.

| 바꾸고 싶은 내용 | 수정할 파일과 방법 |
| --- | --- |
| 영어 표현과 문제 | `src/questions.js`에서 같은 형식의 항목을 복사해 표현, 뜻, 보기, 정답, 해설, 태그를 수정합니다. 문제 ID가 겹치지 않도록 하고 객관식 정답은 보기에 정확히 한 번 넣습니다. 새 태그를 만들면 수첩 목록, 예문 번역과 `src/journal.js`의 쓰임 설명도 추가하세요. |
| 적 체력과 공격력 | `src/engine.js`의 `enemies`에서 해당 적의 `hp`와 `attack` 숫자를 바꿉니다. 같은 곳에 방어력과 보상이 있습니다. |
| 캐릭터와 배경 | `src/art.js`에서 용사, 슬라임, 로완, 숲의 SVG 도형과 색을 수정합니다. 동작과 효과는 `src/effects.css`, 지도·수첩·전투 패널의 꾸밈은 `src/chapter.css`에 있습니다. |
| 대사, 화면과 입력 | `src/game.js`에서 대사, 수첩 목록, 화면을 수정합니다. 버튼을 눌렀을 때의 진행은 `src/controls.js`에 있습니다. |
| 새 스테이지 | 적과 문항, 지도 이름, 수첩 목록을 함께 추가한 뒤 엔진의 스테이지 개방 및 챕터 완료 조건을 조정합니다. 기존 저장 형식을 바꾸면 불러오기 처리도 갱신하세요. |

변경 내용은 [0.2 변경 기록](CHANGELOG.md)에서 확인할 수 있습니다.

수정 후 `node --test tests/engine.test.cjs`로 전투와 저장 규칙을 확인할 수 있습니다. 브라우저 점검 방법과 실제 검증 결과는 [테스트 보고서](TEST_REPORT.md)에 있습니다.
